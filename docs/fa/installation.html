نصب

RTLY در Chrome و Microsoft Edge با یک بسته کار می‌کند. نسخهٔ Firefox وجود دارد ولی آزمایشی است.

بررسی‌شده با کد منبع در 2026-10-08، RTLY 2.0.0.

Chrome#

  1. صفحهٔ RTLY در Chrome Web Store را باز کنید.
  2. روی Add to Chrome کلیک کنید و تأیید کنید.
  3. روی نماد پازل در نوار ابزار کلیک کنید و RTLY را سنجاق کنید.

RTLY به Chrome نسخهٔ ۱۱۱ یا جدیدتر نیاز دارد و خودکار به‌روز می‌شود.

پیام نصب

Chrome می‌گوید RTLY می‌تواند داده‌های شما را در سایت‌های پشتیبانی‌شده بخواند و تغییر دهد. RTLY با همین دسترسی جهت و فونت را روی آن صفحه‌ها تنظیم می‌کند. این دسترسی شامل هیچ سایت دیگری نیست. فهرست مجوزها و دلیل هر کدام در سیاست حریم خصوصی آمده است.

Microsoft Edge#

Edge همان بستهٔ Chrome را به کار می‌برد. می‌توانید صفحهٔ بالا در Chrome Web Store را در Edge باز کنید، یا بستهٔ Chrome را خودتان بارگذاری کنید (بخش «بارگذاری بسته‌نشده»؛ از نشانی edge://extensions استفاده کنید). راه فروشگاه Chrome در Edge برای این نسخه آزموده نشده است.

Firefox (آزمایشی)#

RTLY در Firefox Add-ons نیست. نسخهٔ Firefox به‌صورت فایل zip در صفحهٔ Releases منتشر می‌شود و به Firefox نسخهٔ ۱۲۸ یا جدیدتر روی رایانه نیاز دارد.

  1. فایل rtly-<version>-firefox.zip را از صفحهٔ Releases بگیرید.
  2. در Firefox نشانی about:debugging#/runtime/this-firefox را باز کنید.
  3. روی Load Temporary Add-on کلیک کنید و فایل zip را انتخاب کنید.

Firefox افزونه‌های موقت را هنگام بسته شدن حذف می‌کند؛ پس بعد از هر راه‌اندازی دوبارهٔ مرورگر باید این مراحل را تکرار کنید.

آزمایشی

بستهٔ Firefox از بررسی web-ext lint موزیلا می‌گذرد، اما آزمون‌های پروژه آن را در Firefox واقعی اجرا نکرده‌اند. ممکن است جهت‌دهی، پنجرهٔ افزونه، میان‌بر یا منوی راست‌کلیک آنجا متفاوت رفتار کند. لطفاً آنچه می‌بینید را گزارش دهید.

بارگذاری بسته‌نشده (Chrome یا Edge)#

برای آزمودن نسخه‌ای که هنوز در فروشگاه نیست یا برای اجرای کد منبع.

  1. فایل rtly-<version>-chrome.zip را از صفحهٔ Releases بگیرید و از حالت فشرده درآورید؛ یا از مخزن کد، پوشهٔ extension را به کار ببرید.
  2. chrome://extensions (یا edge://extensions) را باز کنید و Developer mode را روشن کنید.
  3. روی Load unpacked کلیک کنید و پوشه‌ای را انتخاب کنید که manifest.json در آن است.

افزونهٔ بسته‌نشده خودکار به‌روز نمی‌شود. برای به‌روزرسانی، فایل‌های پوشه را جایگزین کنید و روی دکمهٔ بارگذاری دوبارهٔ کارت افزونه کلیک کنید.

حذف#

روی نماد RTLY راست‌کلیک کنید و Remove from Chrome (یا Edge) را بزنید. تنظیم‌هایی که RTLY در مرورگر ذخیره کرده با افزونه پاک می‌شوند. جای دیگری چیزی ذخیره نشده است.
