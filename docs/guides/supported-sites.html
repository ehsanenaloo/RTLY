How well each site works#

Each site has its own small set of rules, because each site builds its pages differently. The project tests five of them in a real Chromium browser, with local copies of their page structure: ChatGPT, Claude, Gemini, Perplexity and Mistral. The other eleven are covered by consistency checks only. None of the tests loads the live sites.

Sites change

AI sites change their page markup without notice. When that happens RTLY can stop working on a site, or work only partly, until its rules are updated. If a site looks wrong, send a broken-site report with the address and a screenshot.

Sites that are not supported#

Any site that is not in the table: other chat tools, search engines other than Bing's chat pages, social networks and so on. RTLY does not run there, and it has no permission to.

The address matters. For example, x.com (Grok inside X) and Google's AI Overviews in search results are not covered. Hugging Face is covered only under /chat.

Ask for another site#

Open a feature request with the site address. Adding a site means writing its rules and giving the extension permission for its address, so some requests will be declined to keep the permission list short. If you write code, the contributing guide in the repository explains how to add a site.
