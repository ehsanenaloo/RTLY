Installation

RTLY works in Chrome and in Microsoft Edge from the same package. A Firefox build exists but is experimental. This page covers each way to install, update and remove it.

Checked against the source on 2026-10-08, RTLY 2.0.0.

Chrome#

  1. Open the RTLY page on the Chrome Web Store.
  2. Click Add to Chrome and confirm.
  3. Click the puzzle icon in the toolbar and pin RTLY.

RTLY needs Chrome 111 or newer. Chrome updates it automatically.

Install prompt

Chrome tells you that RTLY can read and change your data on the websites it supports. That access is how RTLY sets direction and font on those pages. It does not apply to any other site. Privacy, permissions and data lists every permission and what it is for.

Microsoft Edge#

RTLY is on Microsoft Edge Add-ons. Open that page in Edge and click Get. Edge uses the same package as Chrome, so you can also load the Chrome zip yourself as described in Load it unpacked (use edge://extensions).

Firefox (experimental)#

RTLY is not on Firefox Add-ons. A Firefox build is published as a zip file on the Releases page. It needs Firefox 128 or newer on a computer.

  1. Download rtly-<version>-firefox.zip from the Releases page.
  2. In Firefox, open about:debugging#/runtime/this-firefox.
  3. Click Load Temporary Add-on and choose the zip file.

Firefox removes temporary add-ons when it closes, so you repeat these steps after each restart.

Experimental

The Firefox package passes Mozilla's web-ext lint check, but it has not been run in a real Firefox by the project's tests. Direction handling, the popup, the shortcut and the right-click menu may behave differently there. Please report what you find.

Load it unpacked (Chrome or Edge)#

Use this to try a version that is not in the store yet, or to run the source code.

  1. Download rtly-<version>-chrome.zip from the Releases page and unzip it. Or, from the source repository, use the extension folder.
  2. Open chrome://extensions (or edge://extensions) and turn on Developer mode.
  3. Click Load unpacked and choose the folder that contains manifest.json.

An unpacked extension does not update by itself. To update it, replace the folder's files and click the reload button on the extension card.

Pin the icon#

Click the puzzle icon in the toolbar and click the pin next to RTLY. In Firefox, use the extensions button in the toolbar.

Update#

Store installs update by themselves. To check by hand in Chrome, open chrome://extensions, turn on Developer mode and click Update. Your settings are kept.

Remove#

Right-click the RTLY icon and choose Remove from Chrome (or Edge). The settings RTLY saved in your browser are removed with the extension. Nothing is stored anywhere else.
