Limits and known problems

RTLY does one narrow job. This page lists where it stops and what the project has not verified.

Checked against the source on 2026-10-08, RTLY 2.0.0.

What RTLY does not do#

  • It does not translate, spell-check or rewrite anything.
  • It does not change the language of the sites' own interface.
  • It does not work on sites outside the list of 16.
  • It does not process embedded frames, only the top page.
  • It does not keep its settings in sync between browsers or computers.

Behavior limits#

  • Direction is decided from letters only. Digits, punctuation and letters of other scripts (for example Cyrillic or Chinese) are not counted.
  • A single container with more than 5000 characters of text gets the font but no direction.
  • Blocks that contain an icon get the font but no direction on most sites.
  • Code is always left-to-right.
  • The font size changes the page's base size. Text sized in fixed pixels does not scale.
  • Switching a site on or off reloads its open tabs.
  • The Bing, Mistral and Cohere entries cover their whole host, so RTLY also runs on pages there that are not chat pages. For Bing this includes search results.

What has not been verified#

Be aware

These are limits of the testing, not known failures.

  • Live sites. The automated tests use local fixture pages that imitate the structure of five sites (ChatGPT, Claude, Gemini, Perplexity, Mistral). They do not load the real sites, and the other eleven sites have no browser test. Sites change without notice, so a passing test does not prove a site works today.
  • Firefox. The Firefox package passes Mozilla's lint, but it has not been run in a real Firefox by the project's tests. It is experimental.
  • Edge and other Chromium browsers. They use the Chrome package. They were not tested separately.
  • Translations. Not reviewed by native speakers apart from the author's own. In ten languages eight strings are still English, and the browser-level text (name, description, shortcut label) is translated for 10 of the 15 languages.
  • Accessibility. The popup and settings page use labeled controls and keyboard-operable switches. They were not tested with a screen reader.
  • Mobile browsers and private windows. Not tested.

Known oddities#

  • The font file is made available to the supported sites, so a site could detect that RTLY is installed.
  • A few site-specific style rules are loaded on those sites even when you switch RTLY off for them. They are limited to small layout variables; whether any of them has a visible effect on a disabled site has not been tested.
  • The About text inside the extension still reads "All rights reserved", while the project is MIT licensed. The license in the repository is the one that applies.
